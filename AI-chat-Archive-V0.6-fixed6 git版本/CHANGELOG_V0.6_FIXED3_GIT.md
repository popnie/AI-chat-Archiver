# V0.6 fixed3

在 V0.6fixed2 基础上修复：

1. Gemini 时间线 hover 文本框在不同 Chrome 窗口中偶发不显示
   - 强化 Gemini 选择器与用户消息识别
   - 增强右侧时间线全局 hover 触发带
   - 为时间线条与 hover 面板增加窗口尺寸变化后的自动回收/纠偏，避免因不同窗口尺寸共享坐标导致面板跑出可视区

2. 时间线重点图标改为红色爱心
   - 时间线上的重要标记由 🌟 改为 ❤️
   - 重要标记改为仅显示大红色爱心，不再显示圆形底托

3. 中英切换滞后导致导出弹窗语言不一致
   - 页面侧语言状态同步到 document dataset 与页面脚本
   - 导出弹窗改为每次点击时按当前语言重新创建，避免旧语言缓存
