### 📦 安装指南
1. 下载本仓库的 `.zip` 压缩包并解压，或者使用 `git clone` 克隆到本地。
2. 打开 Chrome 浏览器，在地址栏输入 `chrome://extensions/` 进入扩展程序页面。
3. 开启页面右上角的 **“开发者模式”**。
4. 点击左上角的 **“加载已解压的扩展程序”**，选择刚刚解压的文件夹即可完成安装。

### 📦 Installation
1. Download the `.zip` file from this repository and extract it, or `git clone` the repository.
2. Open your Chrome browser and navigate to `chrome://extensions/`.
3. Enable **"Developer mode"** in the top right corner.
4. Click **"Load unpacked"** in the top left corner and select the extracted folder.
