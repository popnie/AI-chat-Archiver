## 中文

### 项目简介

**AI聊天存档大师** 是一款面向 AI 对话场景的浏览器扩展，帮助你将有价值的聊天内容进行归档、整理、回看与展示。  
不管是灵感火花、研究资料、写作草稿，还是那些“这段回答以后一定还会用到”的高质量对话，它都值得被保存，而不是淹没在历史记录里。

简单来说，它做的事很务实：

- 帮你把重要对话留住
- 帮你把内容整理清楚
- 帮你在需要时迅速找回来
- 让 AI 聊天记录从“临时窗口”变成“长期资产”

### 核心亮点

- 📦 **对话归档**：把高价值 AI 聊天内容稳定保存下来
- 🗂 **内容整理**：让碎片化对话更有结构，不再东一块西一块
- 🔍 **快速回看**：回顾历史内容更轻松，查找重点更高效
- 🧠 **思维导图展示**：适合梳理复杂讨论、知识脉络与主题结构
- 🌏 **中英文双语展示**：项目主页、素材展示和对外介绍都更完整
- ⚡ **轻量易用**：装上就能用，不需要折腾复杂流程

### 为什么做这个项目？

因为很多 AI 对话都很有价值，但默认都很“易逝”。  
你明明和 AI 聊出过好东西，却经常在未来某一天只剩一句：

> “我记得之前有一段特别好的回答，但我找不到了。”

**AI聊天存档大师** 就是为了解决这个问题。  
它不负责制造灵感，但负责帮你别把灵感弄丢。

## English

### Overview

**AI Chat Archive Master** is a browser extension designed to help you archive, organize, revisit, and present valuable AI conversations.

Whether it is a great idea, a research note, a writing draft, or one of those *“this answer is too good to lose”* moments, it deserves a better fate than vanishing into endless chat history.

In practical terms, this project helps you:

- save important conversations
- organize them into something more usable
- find them again when you actually need them
- turn temporary chats into long-term knowledge assets

### Key Features

- 📦 **Conversation Archiving**: keep valuable AI chats safely preserved
- 🗂 **Better Organization**: make scattered conversations easier to manage
- 🔍 **Fast Review**: revisit previous discussions with less digging and more clarity
- 🧠 **Mind Map View**: understand complex topics through visual structure
- 🌏 **Bilingual Presentation**: cleaner project showcase for both Chinese and English audiences
- ⚡ **Lightweight Workflow**: install it and get to work, without wrestling with complexity

### Why This Project Exists

Because useful AI conversations are surprisingly easy to lose.

You may have had an excellent exchange with an AI yesterday, only to realize later that it has disappeared into the infinite scroll zone of history.

At some point, almost everyone says:

> “I know I had a really good answer before... I just can’t find it anymore.”

**AI Chat Archive Master** exists to fix exactly that.  
It may not create the brilliance for you, but it does make sure the brilliance is not accidentally buried.

### 安装说明（中文）

**Chrome / Edge / 360 / Opera / Brave / Vivaldi / Arc：**  
可在 Chrome Web Store 搜索 **`AI chat Archiver`** 进行安装。

**Firefox：**  
可直接通过下方地址安装：  
https://addons.mozilla.org/zh-CN/firefox/addon/ai-chat-archiver/

**急用用户：**  
如需尽快使用，可以先下载仓库中的个人分发版，下载后双击即可安装。  
如果你已经把安装包发布到了 Releases，建议优先从 Releases 页面下载安装。

### Installation Notes (English)

**Chrome / Edge / 360 / Opera / Brave / Vivaldi / Arc:**  
Search for **`AI chat Archiver`** in the Chrome Web Store.

**Firefox:**  
Install directly from:  
https://addons.mozilla.org/zh-CN/firefox/addon/ai-chat-archiver/

**Need it urgently?**  
You can use the personal distribution build from this repository. Download it and double-click to install.  
If you have already published the installer in Releases, using the Releases page is recommended.
